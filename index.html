Phase 2 · AI 영향도 분석 및 코드 자동화
8 – 10
✅
8
영향도 분석 실행 (Type 1 / Type 2 분기) 가동 중
  • 🧩 상태 그래프(LangGraph) 기반 정식 경로로 전환 — 중단된 지점부터 재개, 사람 확인 지점 삽입 가능
  • 🛡️ AI 호출 한도 가드 — 시간·일 상한 + 한도 오류 시 자동 차단(반복 호출로 주간 한도를 태우지 않게)
  • ⏹️ 진행 중 분석 즉시 중단 지원 — 중단해도 다음 분석은 처음부터 새로 시작
🔵 Type 1 — 독립 커스텀
  • ① 표준 AS-IS / TO-BE 버전 코드 로컬 캐시 확보
  • ② 표준 AS-IS → TO-BE 변경 diff 생성
  • ③ 커스텀 AS-IS 코드 캐시 확보
  • ④ 표준 AS-IS와 커스텀 AS-IS를 비교해 커스텀 수정 패치(delta) 추출
  • ⑤ 관련 코드 블록만 선별 (200KB 상한 적용)
  • ⑥ Claude 분석 → 이식 시 충돌 지점 + 수정 계획
🟣 Type 2 — 표준+커스텀 연동
  • ① 커스텀 프로젝트 전체 커밋 이력을 패치 형태로 추출
  • ② TO-BE 표준 코드 캐시 확보
  • ③ Claude 분석 → 커밋 이력 + TO-BE 표준 기준으로 재적용 충돌 지점 + 가이드 도출
  • ⚠️ 항상 수동 재적용 필요
📋 공통 출력 결과
  • 🎯 위험도 판정: 낮음 / 중간 / 높음 + 충돌 지점 목록 + 수정 계획
  • 💬 Redmine 댓글 초안 자동 생성
  • ⚠️ JDK 21 마이그레이션 주의사항 자동 추가 (대상 버전 이상인 경우)
  • ❌ 커스텀 코드 미확보 등 치명적 오류 → "판단 불가" 처리
🔄
9
분석 결과 표시 → 개발자 검토 후 수락 부분 가동
  • 🖥️ 어떤 파일을 어떻게 수정할지 diff 형태로 대시보드에 표시
  • 🔀 분석 단계에 따로 있던 검토 관문을 수정 단계의 승인 관문으로 통합 — 승인 지점이 두 곳으로 갈려 아무도 보지 않던 검토 대기가 쌓이던 문제를 정리
  • ✏️ 개발자가 프롬프트를 추가 입력해 재분석 요청 예정
🔄
10
코드 수정안 자동 생성 → 개발자 확인 부분 가동
  • 📦 작업본을 격리한 사본에서 수정 — 원본 소스와 표준 모듈은 건드리지 않음
  • 🔒 외부 통신 허용 목록을 둔 샌드박스 안에서 실행
  • 2️⃣ 두 단계로 나뉨 — ① 요구사항 수정안(미리보기) → 사람 승인 → ② 필수 점검(버전 이관 시 확인해야 하는 항목)
  • 🔨 갈 버전 환경에서 빌드 검증 — 손대기 전 상태와 비교해 이 수정이 만든 오류만 골라냄
  • 🛑 미리보기 고정 · 자동 PR·푸시 금지 안전장치 유지

🗣️ 요구사항 인터뷰 우선 흐름
  • ❓ 계획을 세우기 전에 모호한 점을 사람에게 되묻고, 그 답을 실행 계약(목표 · 완료 조건 · 확인 방법)으로 굳힘
  • 📏 모호성 점수는 측정값만 표시 — 아직 못 잰 구간은 "재지 않음"으로 그대로 표기
  • ✅ 완료 조건 중 기계가 볼 수 있는 것(표준 미수정 · 사이트 격리 · 빌드 성공 등)은 자동 판정, 나머지는 사람 확인으로 명시
📎 첨부 처리 — 첨부 단위 작업
  • ✂️ 작업 단위를 일감 → 첨부 하나로 내림. 한 파일이 오래 걸려도 나머지 파일과 마무리는 그대로 진행
  • 💾 성공한 파일은 그 자리에서 저장 — 재시도가 앞에서 한 일을 되돌리지 않음
  • 👁️ 어떤 파일에서 무엇을 하는 중인지(다운로드 · 변환 · OCR) 화면에 실시간 표시
  • 🔤 한국어 OCR 우선 적용 후 단계별 폴백 — 이미지·PDF 첨부에서 본문 확보
🔔 목록·대시보드 실시간 신호
  • 🚩 일감이 어디까지 왔는지 목록에서 바로 보임 — 시작 전 / 인터뷰 중 / 계획 완료 / 코드 변경안 있음 / 처리 불가
  • 👤 "누구 차례"를 구분 — 답변 대기 · 승인 대기 · 멈춤
  • 📬 작업이 끝나면 어느 화면에 있어도 알림 + 클릭 이동
  • ⚡ 상세에서 바꾸면 목록·대시보드에 즉시 반영 (새로고침 불필요)
🧰 운영 축
  • 🤖 사용자별 AI 계정 + 시간 단위 대여 — 분석·챗봇·수정이 요청자 계정으로 실행
  • ⚙️ 반복 운영 작업 자동화 틀(일감 자동완료 · 주간 회고 기록 등) — 3종 등록, 활성화 대기 운영 전환 전
  • 🖥️ 인프라 현황 탭 — VM 현황·점유, 도커 서버, 빌드 환경, 버전별 표준 DB 스키마 비교
  • 💬 사내 문서 RAG 챗봇 — 문서 + 함수 단위 코드 검색, 벡터와 전문 검색을 함께 사용
🛡️ 품질·보안

  • 🔒 개발용 코드 편집기를 대시보드 로그인 세션으로 게이트 (별도 비밀번호 제거)
